# Decentralized Escrow and Milestone-Based Logistics Platform

A blockchain-based web application that aims to provide secure escrow payments and milestone-based fund releases for logistics transactions using Ethereum smart contracts.

> **Project Status:** Initial setup in progress

## Current Progress

* ✅ React project initialized
* ✅ Ethereum libraries installed
* ⏳ Smart contract development
* ⏳ Wallet integration
* ⏳ Frontend implementation
* ⏳ Backend development (REMIX and Solidity)

### Start the development server

```bash
npm install -D @vitejs/plugin-react
```

```bash
npm run dev
```

The application will be available at the local machine, then click the  URL shown in your terminal (`http://localhost:5173`).
